# CalculatorOverlay

Minecraft の任意の GUI 画面上にドラッグ可能なフローティング電卓パネルをオーバーレイするクライアント専用 Forge MOD です。

## 機能

- **表示切替** — 任意の GUI 画面で `C` キー（変更可能）を押して電卓を開閉
- **リアルタイムプレビュー** — 式を入力すると `= 結果` をリアルタイムで表示
- **Enter で計算** — Enter キーで結果を計算し、式を置き換え（連鎖計算が可能）
- **プレビューをクリック** — 結果をクリップボードにコピー
- **完全なテキスト編集** — カーソル移動、テキスト選択、Ctrl+C/X/V/A、矢印キー、Home/End
- **テンキー対応** — テンキーの数字・演算子をすべて使用可能
- **ドラッグ可能** — タイトルバーをドラッグしてパネルを自由に移動
- **画面をまたいで表示を維持** — GUI を切り替えても表示が続く、ワールドからログアウト時に自動リセット
- **ダークモダン UI** — フォーカス時のボーダーハイライト、閉じるボタンのホバー時赤色表示
- **対応演算子**：`+` `-` `*` `/` `^` `( )` `.` および Unicode `×` `÷`
