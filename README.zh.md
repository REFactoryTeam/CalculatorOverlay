# CalculatorOverlay

一个纯客户端 Minecraft Forge Mod，在任意 GUI 界面上叠加一个可拖拽的浮动计算器面板。

## 功能特性

- **切换显示** — 在任意 GUI 界面按 `C` 键（可重新绑定）开关计算器
- **实时预览** — 输入表达式时下方实时显示 `= 结果`
- **回车求值** — 按 Enter 计算结果并替换表达式，方便链式计算
- **点击预览区** — 一键将结果复制到剪贴板
- **完整文本编辑** — 光标定位、文字选择、Ctrl+C/X/V/A、方向键、Home/End
- **小键盘支持** — 小键盘上的数字和运算符均可使用
- **可拖拽面板** — 拖拽标题栏自由移动位置
- **跨界面保持显示** — 切换 GUI 时保持可见，退出世界后自动重置
- **深色现代 UI** — 聚焦时边框高亮，关闭按钮悬停变红
- **支持运算符**：`+` `-` `*` `/` `^` `( )` `.` 及 Unicode `×` `÷`
